    Requirements and model availability

    ArcGIS Online requires a Professional or Professional Plus user type and a role with imagery-analysis and publishing privileges. The selected portal must expose Detect Objects Using Deep Learning through its raster-analysis service.

    Analysis uses the original WU Ortho image service, not a map screenshot or the analyze-image API. The current map extent is clipped to the imagery bounds and captured when you run. Cell size uses the source's Web Mercator map units (EPSG:3857). Keep this page open until the job finishes or cancellation is confirmed.

    If Run model is disabled, its status and tooltip explain the blocker. The map must stop moving and overlap the WU Ortho imagery, but background tile loading does not prevent server analysis. Changing the map bounds or model settings resets credit consent.

    Results can contain a hosted item ID or a feature-service URL. Both are loaded as map layers; saved-output links open the portal item or the returned service URL, respectively.

    Canceling asks the server to stop; it does not refund credits already used or delete outputs. If the connection fails, use the job-status link before retrying.
